# 8/10 Balance Design Prep

This build keeps the 7of7b game code and visuals intact.
The purpose of this step is to prepare the next tuning phase: stage layout, score values, and how each ingredient should feel.

## Current stage roles

- MELON SODA: left side, tall target, visually strongest. Best for dramatic DIVE moments.
- CAKE: center-left, horizontal target. Best for LAND / SASARI moments.
- COFFEE: center, smaller calm target. Best for controlled shots.
- SPOON: low center-right obstacle. It adds a soft bounce but is visually readable.
- BILL: small vertical obstacle between cake and coffee. Text is removed in 7of7b.
- COASTER: small low obstacle between melon and cake. It adds small table noise.
- LAUNCHER: right side. Current right-to-left slingshot feel is preserved.

## Current ingredient roles

- CHERRY: light, bouncy, feels lively.
- SUGAR: heavy, drops quickly, feels deliberate.
- STRAWBERRY: middle-weight, rounder arc, feels like the classic cake item.

## Current bag system

Every shift uses a shuffled five-item bag:

- CHERRY x2
- SUGAR x2
- STRAWBERRY x1

This gives variety without extreme randomness.

## Tuning principle

Do not tune scores before confirming the stage silhouette.
First confirm that each menu item looks inviting and the shot paths feel readable.
Then adjust points so the player naturally discovers the intended pairings.

## Next recommended work

1. Play 10 shifts and record common scores.
2. Check whether players naturally aim for classic pairings.
3. Decide whether each target has a clear role.
4. Adjust score values only after that.
