# 純喫茶ダイブ / Junkissa Dive

Web Port **3/7 Poster Color Base**.

## 目的

2/7で安定したWeb版の動きを保ったまま、見た目を「レトロ喫茶ポスター」方向へ寄せる最初の版です。

## 変更点

- ポスター風の共通カラーパレットを追加
- タイトル画面をクリーム色・深緑・赤アクセント中心に変更
- ゲーム中の壁・テーブル・背景をポスター風の色面に変更
- コーヒー、ケーキ、メロンソーダの色と形を少し整理
- KISSA FORTUNE の色を木目・金色・赤針方向へ変更
- レシート画面の色を新しい世界観に合わせて調整

## 変更していないもの

- 物理挙動
- 当たり判定
- 配点
- ステージ配置
- シーン推移

## 確認ポイント

1. 2/7と同じように最後まで遊べるか
2. 背景が明るくなっても、食材とターゲットが見やすいか
3. メロンソーダが主役として映えるか
4. 文字が読みにくくなっていないか
5. iPhone Safariで画面の印象が崩れていないか
